Privacy Policy

This application is a private tool for a single user (its owner).

  • It accesses only the owner's own Google data (Google Calendar and Google Contacts), with the owner's explicit consent.
  • OAuth tokens are stored encrypted on the owner's own server. They are never shared with third parties.
  • No data is collected, sold, or transmitted anywhere other than between the owner's server and Google's APIs.
  • The owner can revoke access at any time via their Google Account permissions page.
